# apollo.yml

Lunar Client features through Apollo: waypoints, team view, cooldowns and nametags.

**How it plays:** [:octicons-arrow-right-24: read the guide](../../server/integrations.md#lunar-client-apollo)

## What matters

- **Needs the `Apollo-Bukkit` plugin on the server**; without it nothing here does anything.
- Apollo's own configuration can switch a module off for the whole server, whatever this file says.

Changes apply with `/hcf reload`.

## The shipped file

This is `plugins/HCFCore/apollo.yml` as the plugin writes it on the first start. Every comment is part of the reference. [View it on GitHub](https://github.com/Lawkeys-dev/hcf-core/blob/main/src/main/resources/apollo.yml).
