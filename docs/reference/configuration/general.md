# general.yml

The utility commands: `/spawn`, `/logout`, `/rename` and private messages.

**How it plays:** [:octicons-arrow-right-24: read the guide](../../server/utilities.md)

## What matters

- Turn the whole module off if your essentials plugin already provides these commands.
- `spawn.warmup-seconds` and `logout-seconds` are countdowns that damage or movement cancels.

Changes apply with `/hcf reload`.

This is `plugins/HCFCore/general.yml` as the plugin writes it on the first start. Every comment is part of the reference. [View it on GitHub](https://github.com/Lawkeys-dev/hcf-core/blob/main/src/main/resources/general.yml).
