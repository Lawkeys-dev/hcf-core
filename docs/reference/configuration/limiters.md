# limiters.yml

Enchantment caps, potion caps, and the most of each block a team's territory may hold.

**How it plays:** [:octicons-arrow-right-24: read the guide](../../gameplay/items.md#enchantment-and-potion-caps)

## What matters

- **Every list ships empty** — which levels a map allows is its defining choice.
- A cap can be above vanilla's maximum; the anvil then reaches it.
- `0` forbids an enchantment, an effect or a block.

Changes apply with `/hcf reload`.

## The shipped file

This is `plugins/HCFCore/limiters.yml` as the plugin writes it on the first start. Every comment is part of the reference. [View it on GitHub](https://github.com/Lawkeys-dev/hcf-core/blob/main/src/main/resources/limiters.yml).
