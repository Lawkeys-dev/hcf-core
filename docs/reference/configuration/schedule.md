# schedule.yml

Things on a clock: tips, daily announcements and commands, custom timers, and the key-all.

**How it plays:** [:octicons-arrow-right-24: read the guide](../../server/schedules.md)

## What matters

- **Nothing ships switched on**: tips are off and every list is empty.
- HCFCore has no crates: point `key-all.commands` at your crate plugin.

Changes apply with `/hcf reload`.

## The shipped file

This is `plugins/HCFCore/schedule.yml` as the plugin writes it on the first start. Every comment is part of the reference. [View it on GitHub](https://github.com/Lawkeys-dev/hcf-core/blob/main/src/main/resources/schedule.yml).
