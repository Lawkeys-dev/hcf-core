Tab list ui.yml
Style

HCF grid: four columns of twenty cells in place of the player list - nothing to install. Classic list: the players, each name written from a template. Auto: the grid on an HCF server, the list on a kitmap.

HCF grid

Twenty cells per column; an empty line is a blank cell, and so is a cell whose placeholders are all empty - the grid never shifts. Besides the scoreboard's: %location% %x% %z% %direction% %team_name_line% %members_online% %members_total% %team_balance% %team_points% %members_title% %member_1%…%member_20% %top_team_1%…%top_team_10% %no_event_line% %prefix% %suffix%. A cell may start with its head: [head:self], [head:member:3], [head:top:1] (that team's leader), or any account's skin by name - [head:MHF_Chest], [head:MHF_Question]… - or a mineskin.org skin, [head:mineskin:<id>]. Easier: the Heads list below.

0 is full bars, below 0 none.

Tab list heads ui.yml

The heads beside the HCF grid's titles. Type a player's name, paste a mineskin.org link, or self for the viewer's own; empty turns it into a grey square. Your members always show their own faces, every other cell a grey square. The preview finds a name in mineskin.org's gallery; in game, any account works.
